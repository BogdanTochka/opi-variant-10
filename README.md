# Индивидуальное задание по ОПИ

Вариант 10.

Работа состоит из двух частей:

1. Предварительное исследование предметной области: приложение для оценки качества обслуживания персонала.
2. Разработка программы: расчет стоимости проезда взрослых и детей в автобусе.

## Описание программной задачи

Программа определяет минимальную и максимальную стоимость проезда по количеству взрослых и детей.

Билет стоит один рубль. Каждый взрослый может бесплатно провезти одного сопровождаемого ребенка. Остальные дети оплачивают проезд. Дети не могут ехать без взрослых.

## Структура проекта

- `report.docx` — отчет по индивидуальному заданию;
- `src/main.py` — точка входа программы;
- `src/fare.py` — модуль расчета стоимости проезда;
- `tests/test_fare.py` — тесты модуля расчета;
- `tests/test_cli.py` — тесты консольной программы;
- `tests/check_small_cases.py` — проверка расчета перебором распределений детей;
- `.gitignore` — список файлов и папок, исключенных из Git.

## Запуск программы

```bash
python3 src/main.py
```

